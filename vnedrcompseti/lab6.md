Теоретические основы
Для выполнения данной лабораторной работы выбрали 2 утилиты GPU-Z v0.6.0 и FurMark v1.10.2. GPU-Z выдает лишь информацию о видеокарте, а FurMark проводит тестирование.
GPU-Z - это программа для вывода информации о графическом адаптере, которая поддерживает и карты NVIDIA, и ATI. Она поможет узнать, какая модель видеокарты, определить интерфейс подключения, расскажет о том, какой используется графический процессор (версия BIOS, номер ревизии чипа, частота в 2D, 3D-режимах и при разгоне, сведения о поддержке DirectX). Кроме этого, GPU-Z предоставляет информацию о видеопамяти, а именно ее тип, объем, разрядность шины.

## 7. Вывод о качестве установленного видеоадаптера:

**Intel HD Graphics 2000 - очень слабый видеоадаптер:**

###  **Недостатки:**
1. **Крайне низкая производительность** - всего 2 FPS в тесте FluidMark при разрешении 1366×768
2. **Устаревшая технология** - 32 нм техпроцесс (2011 год), всего 6 исполнительных блоков (EU) 
3. **Отсутствие поддержки** - не поддерживается официальными драйверами в Windows 10 
4. **Производительность ниже 1%** от современных видеокарт 
5. **Базовые частоты** - 650-850 МГц с возможностью boost до 1000-1100 МГц 

### **Назначение:**
- Подходит **ТОЛЬКО** для базовых задач: офисная работа, просмотр видео, веб-браузинг
- **Непригодна** для игр и ресурсоемких графических приложений
- Интегрированное решение начального уровня эпохи Sandy Bridge


## 1. Программы для тестирования видеокарт:

### **Стресс-тесты и бенчмарки:**
- **3DMark** - самая известная программа, симулирующая игровую нагрузку с множеством различных тестов
- **FurMark** - популярный стресс-тест (называемый "бублик") для проверки стабильности GPU 
- **Unigine Heaven / Unigine Superposition** - бенчмарки на движке Unigine 
- **OCCT** - комплексный инструмент для тестирования стабильности 
- **PassMark PerformanceTest** - тестирование производительности 
- **Geekbench 5** - кроссплатформенный бенчмарк
- **Cinebench 2024** - тестирование CPU и GPU с движком Redshift

### **Мониторинг и информация:**
- **GPU-Z** - детальная информация о видеокарте (как в вашем примере) 
- **HWiNFO** - комплексная информация о системе и GPU 
- **MSI Afterburner** - разгон, мониторинг температур и FPS 
- **AIDA64 Extreme** - информация о системе и бенчмарки 

### **Специализированные утилиты:**
- **MSI Kombustor / EVGA OC Scanner / FurMark Asus ROG Edition** - стресс-тесты от производителей 
- **GpuMemTest** - тестирование видеопамяти

## 2. Программы для тестирования мониторов:

### **Комплексные решения:**
- **PassMark MonitorTest** - генерирует 35 тестовых паттернов для проверки качества мониторов и LCD экранов, включая тачскрины и HDR 
- **AIDA64** - в меню "Сервис" есть "Диагностика монитора" для проверки цветопередачи и стабильности 
- **Ultra Mon** - утилита для тестирования и управления мониторами 

### **Проверка битых пикселей:**
- **Dead Pixel Tester** - специализированная проверка на битые пиксели 
- **LCD Monitor Test** - бесплатная утилита для проверки ЖК-мониторов на дефектные пиксели 

### **Другие утилиты:**
- **Nokia Monitor Test** - классический тест мониторов 
- **ScreenTest** - небольшая утилита для тестирования мониторов (в том числе для Linux) 
- **IsMyLsdOK** - проверка монитора на битые пиксели
- **Monitor Test Utility** - портативное приложение для получения информации о мониторе, включая бенчмарки и тесты движения 

### **Профессиональные инструменты:**
- **CalMAN** - профессиональное ПО для калибровки мониторов (используется PCMag) 
- **Power Strip** - тонкая настройка параметров монитора 

Все эти программы помогут комплексно оценить производительность видеокарты и качество монитора!
